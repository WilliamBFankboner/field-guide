Table Specs & Setup

  1. Change dimensions of pop-up window from 400x400 to 500x450 in Part II
  2. Place cursor at beginning of text (below title) and select all paragraphs
  3. Table Menu—>Convert Text to Table, Insert Column to Left
  4. Cell Properties—>set column width to 160, Horizontal Alignment to Left, Vertical Alignment to Top
  5. Table Properties, standardize the two tables to these specs:
    Outside Table: 715, 1, 35, 2 pixels not percentage!
    Inside Table     643, 0, 3, 2 pixels not percentage!
    Style    —>Font: set Primary font to Arial, 8 point, Secondary font to New Times Roman.
  6. To create indents go to HTML source and replace SIZE="3"> with SIZE="3">&
